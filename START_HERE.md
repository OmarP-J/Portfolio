### Option 2: Manual Setup

**Terminal 1 - Backend:**
```powershell
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python -m app.main
```

**Terminal 2 - Frontend:**
```powershell
cd frontend
npm install
npm start
```
